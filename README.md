### 🚀 Featured Projects

#### 🛡️ [ShieldWrite](https://github.com/Mohan-96a/ShieldWrite)
A secure full-stack blogging platform focused on authentication, authorization, and backend security best practices — bridging learning with production-ready identity management systems.

**Tech Stack:** Node.js, Express.js, MongoDB, Mongoose, Argon2, CORS, Dotenv, Nodemon, Postman

**Key Features:**
- Secure signup and login with Argon2 password hashing
- Failed login tracking with automatic account lock and timed unlock
- Role-based access control (RBAC) foundation with user and admin roles
- Blog and comment domain models with author relationships
- Extensible architecture for JWT, MFA, Redis caching, and advanced security

---

#### 🩸 [BloodForAll – Healthcare Donation Platform](https://github.com/Mohan-96a/Blood_For_All)
A web-based healthcare and emergency donation management platform connecting patients, donors, hospitals, and administrators through a unified system for managing blood, medicine, bed, and hospital availability requests.

**Tech Stack:** HTML, CSS, JavaScript, Node.js, Express.js, MongoDB, Google OAuth

**Key Features:**
- Multi-role authentication for Admins, Donors, Hospitals, and Patients
- Blood and medicine donation management with donation history tracking
- Patient request system for blood, medicines, hospital beds, and availability checks
- Hospital dashboard for reviewing, verifying, and responding to requests
- Real-time request status tracking with centralized admin analytics

---

#### 👁️ [Face Recognition Attendance System](https://github.com/Mohan-96a/Automated-attendance-system-using-face-recognition)
An intelligent attendance management system leveraging facial recognition to automate attendance tracking, maintain digital records, and notify absent students via email.

**Tech Stack:** Python, OpenCV, Face Recognition, NumPy, Pandas, SMTP, Excel

**Key Features:**
- Real-time face detection and recognition for automated attendance marking
- Distance optimization feedback to improve recognition accuracy
- Excel-based attendance management with timestamps and duplicate prevention
- Automatic email notifications for absent students via SMTP integration
- Live attendance statistics and multiple-face detection alerts
